# Reading list

Only references that have been checked are listed here. Add to this file as
sources are actually read.

## The dataset
- Kreuger IZM, Merkus VA, de Haan S, Schrader AMR, Scheeren FA, van der Burg SH,
  van Groningen T, Slieker RC, van Doorn R. *Spatial Analysis Reveals Gene
  Expression and Microenvironmental Changes in the Transition of Nevus to
  Melanoma.* Cancer Research (2026). doi:10.1158/0008-5472.CAN-25-2934.
  PubMed 42258703. (Paywalled at time of writing; abstract read only.)
- Supplementary Tables S1-S10 of the above (public, CC BY), Figshare
  doi:10.1158/0008-5472.33414485. Read in full: S1 patient/lesion table with
  library-to-patient mapping; S4-S5 nevus vs melanoma gene lists; S6-S7
  Reactome enrichment; S8 transcription factors; S9-S10 ligand-receptor pairs.
- GEO series GSE298774 - https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE298774

## Methods / tools
- Wolf FA, Angerer P, Theis FJ. *SCANPY: large-scale single-cell gene
  expression data analysis.* Genome Biology 19, 15 (2018).
- Palla G, et al. *Squidpy: a scalable framework for spatial omics analysis.*
  Nature Methods 19, 171-178 (2022).
- Larsson L, et al. *Semla: a versatile toolkit for spatially resolved
  transcriptomics analysis and visualization.* Bioinformatics 39(10), btad626
  (2023). (The R package the depositors used for filtering.)
